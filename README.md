AI Registration Assistant

Overview

AI Registration Assistant is a web-based registration chatbot designed to guide users through a simple internship registration process. It collects and validates user information through an interactive chat interface.

Features

* Interactive chatbot-style registration
* Collects user's full name
* Validates email addresses
* Collects field of study
* Collects programming experience
* Confirmation before completing registration
* Input validation and error messages
* Quick-response buttons for experience level and confirmation
* Help and restart functionality
* Responsive design for desktop and mobile devices

 Registration Flow

The assistant guides the user through the following steps:

1. Full Name
2. Email Address
3. Field of Study
4. Programming Experience
5. Confirm & Submit

Technologies Used

* HTML5
* CSS3
* JavaScript
* Regular Expressions for email validation

How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Start interacting with the AI Registration Assistant.

No server or additional installation is required.

Key Functionalities

The application uses JavaScript to manage the registration state, classify basic user intents, validate inputs, and control the conversation flow.
